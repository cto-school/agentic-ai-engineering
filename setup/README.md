# Course Setup

Complete setup before starting Day 1.

## Required

- Python 3.11 or later
- Git or a downloaded copy of the repository
- JupyterLab or VS Code with Jupyter support
- An instructor-issued OpenRouter course key
- A Python virtual environment

See [installation guide](installation_guide.md) and [accounts/API keys](accounts_and_api_keys.md).
Package installation may be staged by day; account creation remains a separate list
so students do not confuse installing a library with registering for a hosted service.

Instructors should also review the [classroom setup guide](classroom_setup_guide.md).

Local model candidates and the classroom validation process are documented in [model selection](model_selection.md).

## Recommended staged setup

- Before Day 1: Python, notebooks, repository, and the issued OpenRouter key.
- Before Day 2: embedding model and supplied document data.
- Before Day 3: Mem0 Platform and LangSmith accounts for guided hosted-product labs, with local fallbacks available.
- Before Day 5: MCP dependencies.

Students should not be required to create every optional account before the course begins.
